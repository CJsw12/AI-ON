휴대폰 AR 연결 준비

휴대폰 카메라는 신뢰된 HTTPS 연결이 필요합니다. 아래 인증서는 이 PC의 로컬 실습용이며 자동 설치되지 않습니다.

HTTPS 준비 중… 잠시 후 다시 확인해 주세요.
iPhone에서 로컬 인증서를 신뢰하는 방법
  1. 아래 ‘로컬 인증서 받기’를 Safari에서 엽니다.
  2. 설정 → 일반 → VPN 및 기기 관리에서 AI-ON Local AR Development CA 프로파일을 확인한 뒤 설치합니다.
  3. 설정 → 일반 → 정보 → 인증서 신뢰 설정에서 해당 개발 인증서만 신뢰하도록 설정합니다.
  4. 이 페이지로 돌아와 ‘HTTPS로 열기’를 누른 뒤 카메라를 허용합니다.
  5. 실습 후에는 설치한 개발 인증서 프로파일을 삭제할 수 있습니다. 학교 관리 기기 정책은 우회하지 마세요.

카메라 영상은 기기 안에서만 처리하며 PC나 AI에 전송하지 않습니다. AI에는 코드 실행 상태와 질문만 전송됩니다.
