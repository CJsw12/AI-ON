# iPhone 보정 품질 수정 계획

목표: 실제로 표시된 목표를 기준으로 안정된 눈 표본만 학습하고, 검증에 실패한 보정을 성공으로 저장하지 않는다.
범위: IPhoneCalibrationGate.cs, GameController.IPhoneGaze.cs, Tests/IPhoneCalibrationGate.Tests.ps1 및 PROGRESS.md. 기존 로컬 변경을 보존한다. 새 의존성 없음.

1. 표시 전/정착 전 수집 방지, 표본 흔들림·이동·NaN 검사, 검증 오차 한계에 대한 실패 테스트를 먼저 실행한다.
2. 엔진 독립 보정 검사기를 구현한다. 정착1.25초, 열린 눈20개 이상, 각 눈 회전 축의 P10~P90 폭3도 이하와 앞뒤 절반 중앙값 차이1.5도 이하. 이 값은 시작 기준이며 실기 검증 필요.
3. 실제 Repaint 시각부터 정착 시간을 센다. 불안정한 점은 같은 점을 재측정한다. 독립 검증 평균160px/P95 240px 초과는 저장·스토리 자동 진행을 막는다. 저장 보정도 평균 오차를 확인한다.
4. 단위 테스트, 기존 회귀5종, diff check, Unity 재컴파일 및 연결 유지 확인. 실기 정확도는 사용자 참여 후 별도 판정한다.

결정: 체크포인트는 학습에 추가하지 않는다. 낮은 검증 수치를 만들기 위해 모델을 사후 선택하지 않는다. 커밋·푸시는 수행하지 않는다.
