# 눈빛 피하기 선택 교수 이미지

main 2 프로젝트에서 최초 선택한 교수의 웃는 표정 리소스를 사용한다. 기존 시간 경과·피격·결과에 따른 기본/찡그림/웃음 이미지 전환은 적용하지 않으며, 점수·난이도·대사·시선 추적 규칙은 유지한다.

## 실행과 확인

1. Unity 6000.3.23f1에서 main 2 프로젝트의 Main 장면을 Play한다.
2. 학과와 교수를 선택한다. 시선 준비 화면이어도 선택 정보는 저장되어 있다.
3. 상단 메뉴 `Tools → Eye Dodge → Preview Selected Professor`를 실행한다.
4. 제목의 교수 이름, 웃는 표정 이미지, 양쪽 눈의 빨간 발사점을 확인한다. 실제 회피 플레이에는 웹캠 또는 iPhone 보정이 필요하다.

교수를 선택하지 않고 기존 타이틀의 눈빛 피하기로 바로 진입하면 현재 학과의 첫 교수를 사용한다. 이 확인 메뉴는 Editor에서만 제공된다.

## 눈 좌표와 이미지 교체

`ProfessorDodgeEyes.cs`에는 원본 PNG 크기, 양쪽 눈 중심 좌표, 원본 MD5가 기록되어 있다. 현재 main 2의 웃는 표정 이미지 37장을 대상으로 좌표를 마련했다. 최신 main에서 예체능 교수 리소스 3장이 추가 연결되어 해당 이미지의 좌표도 추가했다. 자동 검출 결과를 이미지로 확인하고 잘못 검출되거나 검출되지 않은 눈은 수동으로 보정했다.

Unity가 텍스처를 다른 크기로 가져오더라도 원본의 가로세로 비율을 사용한다. 그림을 그릴 때 사용하는 작은 UV 안쪽 여백을 눈 좌표에도 동일하게 적용한다. 이미지와 눈 반짝임·레이저 발사점은 하나의 변환을 공유한다.

교수 이미지를 교체하면 해당 항목의 원본 크기·눈 좌표·MD5도 갱신해야 한다. `Tools → Checks → Dodge Selected Professor`는 이미지가 달라졌거나 등록된 좌표가 없으면 실패한다. 새로 추가되어 좌표가 없는 리소스는 같은 교수의 얼굴 위치 추정값을 사용하고 경고를 출력하므로, 정확한 발사점은 측정 후 확인해야 한다.

## 검증 범위

Unity 배치 검사에서 32명 교수 각각에 대해 다음을 확인했다.

- 선택한 교수의 Happy 리소스가 로드된다.
- 시작·진행·결과 상태에서도 같은 이미지가 유지된다.
- 원본 이미지와 등록된 좌표의 해시가 일치한다.
- 두 눈이 이미지 안에 있고 좌우 순서가 올바르다.
- 원본 눈 위치와 게임 화면 눈 위치가 UV 여백을 포함해 일치한다.

이는 실제 시선 기기로 게임을 완주한 검증은 아니다. 기존 미커밋 AI 음성 작업은 보존했고 커밋·푸시는 수행하지 않았다.
