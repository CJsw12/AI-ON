## 제출 전 확인할 항목

1. **ElevenLabs TTS** 사용 로그·생성 음성·설정이 별도로 있다면 추가한다. 현재 저장소에 확인된 합성기는 CosyVoice3이므로 초안에는 CosyVoice3를 썼다. 특정 서비스 명칭을 사실과 다르게 바꾸지 않는다.
2. LLM을 통한 구어체 대본 정제의 입력·출력 또는 작업 기록이 있다면, 사용 도구·대본 예시·검수 단계를 추가한다. 현재 확인된 것은 코드 기반 발음 치환이며 이를 LLM 정제로 표현하지 않는다.
3. 순백색 단색 배경을 지정한 실제 이미지 생성 프롬프트를 확보하면 원문 일부와 생성→배경제거→표정 검수 경로를 추가한다. 현재는 그 프롬프트 원문이 확인되지 않았다.
4. 팀원 역할 표는 분담 제안이다. 본인 확인·업무 기록·기여 커밋을 근거로 실제 분담을 확정한다. 커밋 작성자 이름만으로 실명별 역할을 추정하지 않는다.
5. 멘토링 1회의 날짜·멘토명·피드백·반영 근거를 확인한다. Fallback 구현은 확인됐지만 멘토링과의 인과관계는 코드만으로 입증되지 않는다.
6. YouTube·Notion·최신 데모 빌드 URL과 공유 권한을 확정한다. GitHub 주소는 git remote에서 확인했다. 접근 가능 범위는 제출 전 확인한다.
7. 대상 학생의 전공 탐색 불편은 본 신청의 문제 가설이다. 인터뷰·설문 결과를 추가하면 표본 수·질문·결과를 함께 남긴다. 현재 만족도·학습 효과·사용자 수 수치를 만들지 않는다.
