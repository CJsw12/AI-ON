# AI-ON 개발 방식: "Claude가 이끄는 AI 개발 스튜디오" (v0.2)

작성: Claude, 2026-11-26 · 대상: 팀 내부, 대회 발표 준비

> **한 줄 요약**: 학생 팀 몇 명이 대회 지원 Claude Max 계정으로 **Claude를 기술 리드로 둔 AI 개발 스튜디오**를 운영했다. 서로 다른 회사의 AI 3종(Anthropic Claude, OpenAI Codex, Google Antigravity)이 기획·구현·검증을 나눠 맡고 **서로의 결과를 교차 검증**했다. 사람은 방향을 정하고 최종 판단과 실기 검증을 했다.

## 3. 쇼케이스 6선 (발표에서 보여 줄 장면)

### ① AI 3사 교차 검증 — "한 AI를 믿지 않는다"
- 한 회사의 AI가 만든 결과를 **다른 회사의 AI가 검토**한다. Claude 계획 → Codex 검토, Codex 코드 → Claude·Antigravity 리뷰, Antigravity 코드 → Codex 리뷰.
- 같은 회사 모델끼리는 같은 실수를 놓칠 수 있으므로, 다른 회사 모델을 섞어 서로의 맹점을 줄이는 구조다.
- **발표 자료**: "누가 누구의 무엇을 잡았나" 표. 예: *Codex가 Claude 계획서에서 얼굴 노출 위험(치명)을 지적*, *Claude가 Codex 코드에서 영상 뒤집힘 버그를 지적*.
- **목표**: 대회 전까지 교차 검증 30회 이상, 발견·반영 건수 공개.

### ② 기능 하나가 만들어지는 과정 타임랩스
- 수어 지문자 기능을 사례로 **아이디어 → 계획서 v0.1 → 검토 2회 → v1.0 → 병렬 구현 → 리뷰 → 버그 수정 → 컴파일 → 실기**까지 전 과정을 화면 녹화·로그로 남겨 1분 영상으로 만든다.
- 각 단계에 어떤 AI가 무엇을 했고, 사람이 어디서 결정했는지 자막을 단다.

### ③ AI QA 군단 — 스토리 전수 점검
- 16개 학과 스토리와 교수 32명의 대사를 **Claude 서브에이전트 여러 개가 동시에** 나눠 점검한다: 오탈자, 선택지 분기 도달 가능성, 교수별 말투 일관성, 장애·수어 관련 표현 적절성.
- 발견 → 사람이 채택/기각 → 수정 → 회귀 테스트까지를 기록한다.
- **발표 자료**: "AI가 대사 N줄을 점검해 M건 발견, 사람이 K건 채택". 기각한 건도 같이 보여 준다(AI 오탐을 사람이 걸렀다는 증거).
- Max의 넉넉한 사용량 덕분에 한 번에 전수 점검을 여러 번 돌릴 수 있다.

### ④ AI 보이스 스튜디오 — 교수 목소리 제작 자동화
- Claude는 음성을 직접 만들지 못한다. 대신 **로컬 오픈소스 TTS(CosyVoice3) 파이프라인 전체를 Claude가 운영**한다.
  1. 스토리 코드에서 교수별 대사 자동 추출(`Tools/Voice/export_lines.ps1`)
  2. 영어·기호 발음 사전 관리(`generate.py`의 `SAY` 표: `i++` → "아이 플러스 플러스")
  3. 바뀐 대사만 다시 생성, 빠진 대사 음성 삭제
  4. **자동 품질 검사(추가 계획)**: 생성된 음성을 로컬 음성 인식(Whisper 계열)으로 다시 받아 적고, 원래 대사와 글자 오류율을 비교해 기준을 넘는 줄만 사람이 들어 보고 다시 만든다.
- 목소리 복제는 **녹음 제공자가 동의한 본인 목소리만** 쓴다. 실존 교수의 목소리를 무단으로 복제하지 않는다.
- **목표**: 음성 교수 2명 → 동의한 녹음 제공자 수만큼 확대, 줄별 자동 검사 통과율 공개.

### ⑤ 24시간 개발 루프
- 정해진 시간마다 자동 점검을 돌린다: 원격 최신 상태, 회귀 테스트, 미해결 항목 요약(팀 동의 후 설정).
- 사람이 잠든 사이 AI 워커가 명세된 작업을 진행하고, 아침에 사람이 리뷰·채택한다. 사람이 결정하지 않은 커밋·푸시는 하지 않는다.
- **발표 자료**: 하루 동안의 작업 타임라인(사람 결정 시점 vs AI 작업 시점).

### ⑥ AI 개발 관제실 (대시보드)
- 위 활동을 한 화면에 모은 대시보드를 발표 때 띄운다: AI별 기여 커밋, 교차 검증 횟수와 발견 건수, AI 실수를 사람이 잡은 건수, 테스트 수 추이, 음성 제작 현황.
- 숫자는 Git 기록과 검토 기록표에서 자동 집계해 직접 확인할 수 있게 한다.

## 6. 정직하게 밝힐 것

- **결정과 검증은 사람이 했다**: 무엇을 만들지, 어떤 결과를 채택할지, 실기 동작 확인은 팀이 했다.
- **Claude는 TTS를 직접 하지 않는다**: 음성은 로컬 오픈소스 TTS가 만들고, Claude는 파이프라인을 운영한다.
- **구독과 API는 별개**: Max 구독은 Claude 앱·Claude Code 사용용이다. 게임 실행 중 AI 모드는 별도 서버·모델을 쓴다.
- **대회 규정**: AI 사용 고지 방식과 허용 범위를 먼저 확인하고 따른다. 대회 지원 계정의 사용·공유 규칙을 지킨다.
- **개인정보**: 녹화 참여자 데이터와 팀원 개인 정보는 Claude 대화에 올리지 않는다.
