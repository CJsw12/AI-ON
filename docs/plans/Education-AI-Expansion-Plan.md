# 교육용 AI·기기 연동 확장 기획 (초안)

- 기준: GitHub `main` `5571112` (2026-11-27), 팀 아이디어 회의 메모
- 상태: 팀 합의 전 초안. 아래 비용·제약은 2026-11-27 공식 페이지 확인 결과이며 바뀔 수 있다.

## 0. 기획 원칙: "AI는 전문가가 아니라 전공 도구를 미리 다뤄 보게 하는 조교"

모든 확장 기능은 아래 네 줄을 채워야 채택한다. 미니게임 수를 늘리는 것이 목적이 아니다.

1. **학습 목표**: 이 기능으로 학생이 알게 되는 전공 개념·사고방식 한 가지.
2. **AI 역할**: 생성(설계안·문제·대사), 해설(왜 그런지), 대화(음성·자유 답변) 중 무엇인지.
3. **검증**: 정답·안전이 걸린 결과는 AI가 아니라 코드가 확인한다(현재 강의 퀴즈의 "코드 검산 + AI 문장" 구조를 그대로 확장).
4. **대체 흐름**: AI·네트워크·기기가 없어도 같은 학습을 끝까지 할 수 있다(현재 `결정론적 Fallback 다이얼로그` 원칙).

AI가 잘하는 것은 **연결(확장성)**이다. 학생의 말·몸·주변 기기를 받아 전공 맥락으로 바꿔 주고, 전문가 수준은 아니어도 "이 전공에서는 이런 식으로 생각한다"를 체험하게 한다.

## 1. 이미 있는 미니게임으로 보여 주는 교육 효과

심사·발표에서는 "실제 게임에서 이런 역량을 얻는다"를 학과별로 하나씩 보여 준다. AI 확장은 오른쪽 열처럼 기존 게임 위에 얹는다.

| 학과 | 기존 미니게임 | 체험하는 전공 역량 | AI가 더할 수 있는 것 |
|---|---|---|---|
| 컴퓨터공학 | 버그 헌트, 주제 선택 강의 | 코드 실행 흐름 추적, 자료구조·알고리즘 개념 | 틀린 줄을 고른 이유를 교수 말투로 해설, 학생 수준에 맞춘 다음 문제 |
| 스마트시스템공학 | 회로 점검, 배달 로봇 경로 | 멀티미터로 고장 위치 찾기, 명령 순서로 기계 제어 | 자연어 미션 → 명령 순서 제안 → 시뮬 검증 → **실제 드론** (2-D) |
| 화학 | 원자 조립, 결합 설계실(3D), pH 지시약 | 분자식·결합 차수·분자 모양·극성 | 오답 분자의 어디가 틀렸는지 단계별 설명 |
| 생명과학 | DNA 염기쌍, 현미경 초점 | 상보 결합, 관찰 도구 조작 | 관찰한 시료에 대한 질문에 답하는 실험 조교 |
| 심리학 | 스트룹 과제, 행동 관찰 기록 | 인지 간섭, 관찰 기록 코딩 | **워치 심박**으로 과제 중 내 몸의 반응을 데이터로 보기 (2-C) |
| 경영 | 가격 정하기, 계산대 | 이익 = (가격 − 원가) × 판매량 | 내 가격 전략을 평가하는 가상 고객·시장 반응 |
| 체육 | 스트레칭 리듬, 웹캠 스트레칭 | 동작 순서·자세 | **워치 심박**으로 운동 강도 구간 체험 (2-C) |
| 실용음악 | 코드 진행, 믹싱 콘솔 | 화성 진행, 채널 밸런스 | **마이크**로 직접 부른 음정 판정 (2-B) |
| 물리 | 충돌 실험실 | 운동량·충격량 | 실험 결과를 식으로 다시 설명 |
| 사회복지 | (하이라이트) 수어 지문자 | 수어 자음 표현 | 이미 손 추적 + 학습 모델로 구현 중 |
| 건축 | 카드·타이밍(공용) | — (전용 게임 없음) | **AI 평면도 → 폰 AR 책상 투영** (2-E)으로 전용 체험 신설 |

> 건축·기계·미디어·사회복지·연극영화·시각디자인·수학은 아직 공용 게임만 쓴다. 이 학과들은 신규 기획의 우선 대상이다.

## 2. 확장 기획 6가지

### 2-A. AI가 미니게임을 직접 푸는 "AI 조교 시연" + 모바일 연동

- **학습 목표**: 정답만 보는 것이 아니라 풀이 과정을 단계별로 본다.
- **동작**: 학생이 막히면 `AI 조교에게 맡기기`를 누른다. 게임이 현재 상태를 텍스트로 정리해 AI에 보내고, AI는 한 수씩 "다음 행동 + 이유"를 낸다. 게임이 그 행동이 규칙상 맞는지 확인한 뒤 화면에서 실제로 실행한다. 틀린 수는 실행하지 않고 "AI도 틀릴 수 있다"는 표시와 함께 정답 풀이로 바꾼다.
- **모바일 연동**: PC 게임 화면에 QR 코드 → 휴대폰 웹페이지(앱 설치 없이) 접속. 휴대폰에는 AI 조교의 풀이 설명·힌트 채팅이 뜨고, PC 화면은 게임 진행에 집중한다. 통신은 같은 Wi-Fi 안의 로컬 연결(이미 iPhone 시선·워치가 UDP로 PC와 통신).
- **기존 기반**: 강의 퀴즈의 상태 → AI 문장 → 코드 검증 구조, AI 모드 서버(Cloudflare Worker, GPT → Gemini 대체).
- **4주 안 범위**: 버그 헌트·배달 로봇 경로 2종에만 적용. 모바일은 풀이 보기 전용.

### 2-B. 마이크로 플레이하기 (음성 입력 + 실시간 교수 음성)

- **학습 목표**: 전공 개념을 "말로 설명"해 보는 경험(수업 발표·질문 연습).
- **동작**: 키보드 대신 마이크로 교수 질문에 답한다. 음성 → 글자(STT) → 기존 AI 채점 → 교수 답변 → 음성(TTS) 순서. 강의 퀴즈는 보기 번호나 답을 말로 고른다. 실용음악은 AI 없이 마이크 음정 분석만으로 "이 음을 불러 보세요" 판정.
- **STT 후보**: Azure Speech(실시간, 한국어 지원) 또는 ElevenLabs Scribe(실시간). 무료 한도는 5절.
- **교수 목소리로 실시간 답변**: 교수 32명 음성은 지금 로컬 모델(CosyVoice3·Qwen3-TTS)로 미리 만든 파일이다. AI가 즉석에서 만든 답변을 같은 목소리로 읽으려면 (1) 로컬 모델을 실시간으로 돌리거나(GPU PC 필요) (2) 유료 음성 복제(ElevenLabs Starter 이상)를 써야 한다. 무료로는 Azure의 기본 한국어 음성으로 읽고, 교수 목소리는 미리 만든 대사에만 쓰는 방식이 현실적이다.
- **대체 흐름**: 인식이 실패하면 키보드 입력·선택지로 바로 전환, TTS가 실패하면 자막만 표시.
- **4주 안 범위**: 컴퓨터공학 AI 모드 자유 답변 + 강의 퀴즈 음성 답변.

### 2-C. 워치 센서로 내 몸을 데이터로 보기 (블루투스·웨어러블)

- **학습 목표**: 체육학·심리학이 다루는 생리 반응을 "내 데이터"로 체험.
- **동작**:
  - 체육학과: 스트레칭·리듬 동작 중 심박을 실시간 그래프로 보여 주고, 최대심박 대비 강도 구간(가벼움·보통·높음)을 설명한다.
  - 심리학과: 스트룹 과제 전·중·후 심박 변화를 보여 주고 "인지 부하와 각성"을 해설한다. 진단이 아니라 관찰 체험임을 화면에 명시한다.
  - 기계공학과(선택): 워치 가속도·자이로로 손목을 흔들어 진동·가속도 그래프를 직접 만든다.
- **기존 기반**: Galaxy Watch4 → PC 심박·가속도·자이로 수신 파이프라인 구현 완료(게임 연결은 아직 없음).
- **AI 역할**: 측정값을 받아 교수 말투로 그래프 해설(숫자 판정은 코드).
- **주의**: 심박은 민감한 개인정보. 저장하지 않고 화면 표시만, 시작 전 동의.

### 2-D. 드론: 시뮬레이터에서 짠 코드로 실제 드론 날리기

- **학습 목표**: 스마트시스템·기계공학의 "명령 → 제어 → 실제 움직임" 흐름과 시뮬레이션 검증의 필요성.
- **동작**:
  1. 기존 배달 로봇 경로 게임을 3D 드론판으로 확장: 이륙·전진·회전·착륙 명령 블록을 줄 세운다.
  2. 학생이 자연어로 미션을 말하면("책상 위 컵 주위를 한 바퀴 돌고 와") AI가 명령 순서를 제안한다.
  3. 게임 시뮬레이터가 충돌·고도·범위를 검사해 통과한 순서만 실제 드론으로 보낼 수 있다.
  4. 같은 명령을 실제 소형 교육용 드론(예: Wi-Fi SDK를 지원하는 교육용 드론)으로 실행한다.
- **안전 규칙(코드로 강제)**: 실내·저고도·짧은 거리 제한, 프로펠러 가드, 시뮬 통과 전 실기 금지, 비상 정지 키.
- **비용·위험**: 드론 구매 필요, 실내 비행 공간 확보, 기종 SDK 확인 필요(구매 전 검증). 4주 안에는 시뮬레이터 + AI 명령 제안까지, 실제 비행은 발표 시연 1회 목표.

### 2-E. 건축학과: AI 평면도 → 휴대폰 AR로 책상 위에 띄우기

- **학습 목표**: 요구 조건(가족 수·방 개수·채광)을 공간 배치로 바꾸는 설계 사고, 축척 감각.
- **동작**:
  1. 학생이 요구 조건을 말·글로 입력 → AI가 **구조화된 평면 데이터**(방 이름·크기·위치·문·창)를 만든다.
  2. 코드가 검사: 면적 합, 방 최소 치수, 문으로 모든 방이 이어지는지, 창이 있는지. 통과하지 못하면 AI에 이유를 돌려주고 다시 만든다.
  3. PC 게임에서 2D 평면도로 보여 주고 교수가 평가한다.
  4. 휴대폰 AR 앱(Unity AR Foundation)이 같은 데이터를 받아 책상 면을 인식하고 1:100 축척 3D 모형을 세워 보여 준다. 학생은 휴대폰을 들고 돌아보며 동선을 확인한다.
- **왜 이미지 생성이 아니라 구조화 데이터인가**: 이미지 AI가 그린 설계도는 치수·벽 연결이 맞지 않아 검증할 수 없다. 데이터로 만들어야 코드 검사와 3D 변환이 가능하다.
- **범위**: AR은 개발 난도가 가장 높다. 4주 안에는 AI 평면 생성 + 코드 검사 + 2D 표시까지, AR 투영은 시제품 1회 시연 목표.

### 2-F. 수어 지문자 (진행 중)

- 사회복지학과 체험으로 이미 손 추적 + 규칙·학습 분류기를 구현 중이다. AI 확장은 "틀린 손 모양의 어느 손가락이 다른지" 해설을 더하는 정도로 제한한다.

## 3. 공통 구조: PC 게임 + 휴대폰 동반 연결

```
[휴대폰 웹/앱] ──QR 연결, 같은 Wi-Fi── [PC 게임(Unity)] ── [AI 서버(Cloudflare)] ── GPT / Gemini
   AI 조교 채팅                     게임 상태·검증            음성 STT·TTS(Azure / ElevenLabs)
   AR 평면도 투영                    교수 대화·채점
   마이크(선택)                     [워치] 심박·IMU (UDP)
                                   [드론] 명령 (Wi-Fi SDK)
```

- 휴대폰은 1차로 **설치 없는 웹페이지**(채팅·풀이 보기), AR만 별도 앱으로 둔다.
- 모든 연결 기기는 없어도 게임이 끝까지 진행되어야 한다.

## 4. 우선순위와 2단계 4주 제안

| 순위 | 기능 | 이유 |
|---|---|---|
| 1 | 2-B 음성 플레이 | 무료 한도로 바로 가능, 모든 학과에 효과, 시연 효과 큼 |
| 2 | 2-A AI 조교 시연 + 휴대폰 풀이 보기 | 기존 강의 퀴즈 구조 재사용, 교육 의도가 가장 분명 |
| 3 | 2-C 워치 심박 (체육·심리) | 수신 파이프라인 완성, 게임 연결만 남음 |
| 4 | 2-E 건축 AI 평면도 (AR 제외) | 건축학과 전용 체험 신설 |
| 5 | 2-D 드론 시뮬 + 실기 1회 | 장비 구매·안전 공간 필요 |
| 6 | 2-E AR 투영 | 난도 최상, 2단계 이후 |

- 1주: 음성 입력(STT) + 키보드 대체, 휴대폰 QR 연결 뼈대
- 2주: AI 조교 시연(버그 헌트·로봇 경로), 휴대폰 풀이 보기
- 3주: 워치 심박을 체육·심리 게임에 연결, 건축 AI 평면 생성·검사
- 4주: 통합 점검, 드론 시뮬 시연, 데모 빌드

## 5. Azure·ElevenLabs 무료 사용 확인 (2026-11-27 공식 페이지)

### Azure Speech

- **카드 등록만으로 실시간 TTS·STT 사용 가능**: 무료 계정 가입에 신용카드(또는 선불 아닌 체크카드)가 필요하고, 가입 때 $1 임시 승인만 일어난다. 종량제로 직접 올리지 않으면 청구되지 않는다.
- **Speech 무료 등급(F0)**: 신경망 TTS 월 50만 자, 실시간 STT 월 5시간. 실시간(스트리밍) TTS·STT 모두 F0에서 된다. 제한은 실시간 STT 동시 1건, TTS 60초당 20건.
- **한국어**: 실시간 STT(`ko-KR`)와 한국어 신경망 음성 여러 개 지원.
- **주의**: 무료 계정은 30일 또는 $200 크레딧 소진 후 업그레이드하지 않으면 비활성화된다고 안내한다. 이후 F0가 계속 동작하는지는 공식 페이지로 확인하지 못했다.
- **교수 목소리 복제(Personal/Custom Voice)**: F0에서 불가, 별도 승인 필요. 즉 Azure 무료로는 기본 한국어 음성만 쓸 수 있다.
- **학생용 대안**: Azure for Students는 학교 이메일로 카드 없이 $100 크레딧을 준다(공식 페이지 문구, 세부 미확인).

### ElevenLabs

- **카드 등록 불필요**: Free 플랜은 $0이며 API를 쓸 수 있다. 카드 등록 여부는 공식 페이지에 명시돼 있지 않았고, 카드만 등록해서 열리는 기능은 확인되지 않았다.
- **Free 한도**: 월 10,000 크레딧(Eleven v4·v3·Multilingual v2 기준 약 1만 자, Turbo 계열 약 2만 자). AI 답변 120자 기준 약 80회. 실시간 STT(Scribe) 2.5시간, 대화형 에이전트 15분.
- **Free 제약**: API로 Voice Library 음성 사용 불가, 상업 라이선스 없음(저장소의 기존 기록상 비상업·출처 표기 조건), 동시 요청 약 2건.
- **음성 복제**: Instant Voice Cloning은 Starter($6/월)부터, Professional Voice Cloning은 Creator($22/월)부터. 교수 목소리로 실시간 답변하려면 최소 Starter가 필요하다.
- **한국어**: TTS(Eleven v4·v3·Multilingual v2·Flash v2.5)와 STT(Scribe) 모두 지원.
- 2026-12-01까지 할인 행사 표기가 있다.

### 권장 조합
