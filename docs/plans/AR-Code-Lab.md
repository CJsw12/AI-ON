# AR 코드 실행 실험실 (기존 실습과 비교)

사용자 승인 범위: 기존 AI 조교 실습 유지, 컴퓨터공학과 연습 메뉴에 별도 항목 추가, 스토리 미적용·로컬 전용·푸시 없음.

- 순수 C# 실행 모델: [4,8,12] 반복문을 한 줄씩 추적한다. 잘못된 초기화와 수정 후 합계/평균을 비교한다. 계산은 코드, 설명은 현재 상태를 받은 AI가 담당한다.
- PC IMGUI에서 코드 줄·배열·변수 상자를 표시한다. 휴대폰 동일 상태 동기화, 한 줄 실행·처음·수정·AI 질문 입력을 지원한다. 준비 화면은 제한 시간에 넣지 않고 실습은 60초 안에 종료한다.
- WebAR: 로컬 배포한 AR.js/Three.js로 Hiro 학습 카드 추적. 카메라는 버튼으로 시작하고 영상은 휴대폰 안에서 처리한다. 별도 3D 미리보기는 AR이라고 표시하지 않는다.
- 휴대폰 카메라에는 HTTPS 필요. Library의 로컬 개발용 인증서를 사용하며 PC/휴대폰 신뢰 저장소를 자동 변경하지 않는다. HTTP 안내 페이지에서 인증서·설정 방법·HTTPS 링크를 제공한다. 실기 신뢰 설정은 사용자가 한다.
- 단계 경계/수정 후 리셋/빈 입력·AI 실패·연결 종료를 테스트한다. PS 전체·Unity 컴파일·HTTP/TLS 엔드포인트·브라우저 화면을 검사하고 실제 iPhone AR는 별도로 검증한다.

구현 및 자동 검증 완료. 실제 iPhone에서 인증서 신뢰·카메라 허용·인쇄 마커 추적 확인 대기. PC/모바일 크기 화면과 두 버전 계산·TLS·테스트 이미지 인식은 통과했다.
