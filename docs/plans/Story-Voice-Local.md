# 스토리 자동 음성 입력과 독립 음성 대화 (로컬)

구현·자동 검증 완료. 사용자 실마이크 점검 대기.

사용자 요청: 스토리는 기존 분기·채점 그대로 음성 입력만 자동화한다. 자유 대화는 별도 화면으로 분리한다. main 푸시와 원격 병합은 하지 않는다.

1. SpeechTurnGate의 무음·잡음·정상 발화·최대 길이 동작을 먼저 테스트한다.
2. 로컬 Whisper small CPU int8 모델을 프로세스에 유지한다. 한국어와 학과 용어 힌트, 무음 필터를 적용한다. 마이크 선택·레벨·감도를 표시한다.
3. 스토리 자동 모드를 켜면 교수 음성 종료 후 녹음, 1.3초 침묵 뒤 인식, 1.5초 확인 시간을 거쳐 기존 AiSend로 전송한다. 수동 모드·중지·다시 말하기를 남긴다. 메뉴·슬롯 전환·오류 시 취소한다.
4. 타이틀의 별도 1대1 음성 대화 화면에서 학과·교수를 선택한다. 최근 대화만 AI에 전달하고 스토리 상태·점수는 건드리지 않는다. 교수 이름·성격·학과를 유지한다. 동적 답변은 설치된 Windows 한국어 TTS로 재생한다(교수 복제 음성과 구분 표기). TTS 동안 녹음을 중단한다.
5. 회귀 PS 전체, 음성 게이트 테스트, C# 컴파일, 실제 한국어 음원 변환 및 TTS WAV 생성, 가능하면 Unity 화면을 검사한다. 실마이크 인식률 향상 수치는 동일 녹음 비교 없이는 주장하지 않는다.

주의: 무음 입력은 보내지 않고, 실패 시 자동 재전송하지 않는다. 작업 종료 시 마이크·음성 프로세스를 해제하고 임시 녹음을 삭제한다. Windows 로컬 확인용이며 빌드 배포는 Python 도구 동봉이 추가로 필요하다.

최신 변경: 별도 대화는 수동 텍스트 질의응답으로 변경했으며 마이크·TTS를 사용하지 않는다. 스토리 입력만 음성을 사용한다. 실습은 대학 신입생 수준의 평균 계산·변수 추적을 유지한다. medium 옵션은 다운로드 및 실마이크 검증이 남아 있다.
