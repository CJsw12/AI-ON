# AI-ON · 두근두근 교수님

대학교 첫 학기를 배경으로 한 **연애 시뮬레이션 비주얼 노벨**입니다. 네 학부 중 하나의 신입생이 되어 교수님 두 분 중 한 명을 골라, 입학 OT부터 팀 프로젝트 마무리까지 6개 챕터를 함께합니다.

- 엔진: **Unity 6000.3.23f1** (다른 버전으로 열면 프로젝트가 업그레이드되니 꼭 같은 버전을 쓰세요)
- 화면: IMGUI로 직접 그리는 1280×900 고정 캔버스. 창 비율이 달라도 여백(레터박스)으로 맞춥니다.
- 씬: `Assets/Scenes/Main.unity` 하나

## 📢 팀원 공지

1. **미니게임 담당자는 [`MINIGAME_GUIDE.md`](MINIGAME_GUIDE.md)를 먼저 읽어 주세요.**
   문서를 통째로 AI에게 붙여 넣고 "이 규칙대로 ○○ 미니게임 만들어 줘"라고 하면 됩니다. 결과물은 C# 파일 1개이고, `Assets/Scripts/`의 같은 이름 파일과 바꾸면 끝입니다.

   | 미니게임 | 바꿀 파일 |
   |---|---|
   | 카드 짝맞추기 | `Assets/Scripts/CardMatch.cs` |
   | 타이밍 맞추기 | `Assets/Scripts/LoopTiming.cs` |
   | 커피 제조 | `Assets/Scripts/CoffeeOrder.cs` |

   세 미니게임 모두 팀원 완성본이 들어가 있습니다 (카드: 미리보기 후 섞기 · 60초, 타이밍: 연습 + 3단계, 커피: 교수님 음료 + 동기 주문 2잔 · 60초). 네 학부가 같은 게임을 쓰고, 제목·대사·카드 내용 같은 글자만 학부마다 `MiniGameTheme`으로 바뀝니다. 고칠 때는 클래스 이름과 생성자 형태(`MiniGameTheme theme`를 받아 `base(theme)`)만 유지하면 나머지 게임과 충돌하지 않습니다. 시간은 `Time.unscaledTime` 대신 기본 클래스의 `Now`를 써 주세요(설정 창이 열리면 멈춤).
2. 가이드는 게임 쪽 규칙이 바뀔 때마다 같이 갱신됩니다. 작업 전에 `git pull`로 최신 버전을 받아 확인해 주세요.
3. 새 파일을 추가하면 Unity가 만드는 `.meta` 파일도 **같이 커밋**해 주세요. 빠지면 다른 사람 컴퓨터에서 참조가 깨집니다.
4. 네 학부 스토리가 모두 들어가 있습니다. 새 학부는 [`STORY_GUIDE.md`](STORY_GUIDE.md)로 만들 수 있습니다. 새 학부의 교수님 사진은 아직 AI-SW융합학부와 같은 두 장(엄격한 교수 · 유쾌한 교수)을 쓰고, 이름만 다릅니다. 학부별 사진이 나오면 교체할 예정입니다.
5. 엔딩 조건, 특히 숨겨진 엔딩은 README나 커밋 메시지에 적지 말아 주세요. 직접 찾는 게 재미입니다 🤫

## 실행 방법

1. Unity Hub에서 이 폴더를 **6000.3.23f1**로 엽니다.
2. `Assets/Scenes/Main.unity`를 열고 ▶ Play.
3. 빌드: File → Build Profiles에서 `Main` 씬 하나만 넣으면 됩니다.

## 게임 흐름

- **인트로** → **타이틀**(학부 선택 · 이어하기 · 미니게임 연습 · 엔딩 도감 · 설정) → **경험 선택**(AI-SW는 전공자 / 비전공자, 다른 학부는 경험자 / 입문자) → **교수님 선택** → 챕터 1~6 → **엔딩**
- 챕터마다 선택 자리가 2개씩, 모두 12개입니다. 학부마다 순서와 위치는 다르지만 구성은 같습니다.
  - 일반 선택지 6개: 교수님 성격에 따라 호감도가 오르거나 내립니다.
  - 문제 3개: 경험자는 답을 **직접 입력**하고, 입문자는 쉬운 **객관식**을 풉니다. 정답이면 호감도 +2, 오답이어도 감점은 없습니다.
  - 미니게임 3개: 성적에 따라 호감도 +0~2.
- 엔딩은 학부의 교수님마다 8개입니다. 호감도와 플레이 성향(질문 · 협업 · 관심 · 혼자 해결)에 따라 정해집니다.

### 학부와 교수님

학부는 대학별로 묶여 있습니다. 타이틀 · 엔딩 도감 · 미니게임 연습에서 대학 탭(공과대학 · 자연과학대학 · 인문사회대학 · 예체능대학)을 고른 뒤 학부를 고릅니다. 아직 학부가 없는 대학은 "준비 중"으로 보입니다.

모든 학부의 교수님은 엄격한 원칙파("~합니다 / ~하세요")와 유쾌한 소통파("~해요 / ~죠!") 두 분입니다.

| 학부 | 첫 학기 이야기 | 엄격한 교수 | 유쾌한 교수 | 문제 (챕터) | 미니게임 (챕터) |
|---|---|---|---|---|---|
| AI-SW융합학부 | 첫 코딩 수업과 팀 프로젝트 발표 | 김가람 | 이명희 | 3 · 4 · 6 | 카드 2 · 타이밍 3 · 커피 5 |
| 스마트시스템공학부 | 정전된 OT에서 시작해, 운행 중단 위기의 배달 로봇 "배달이" 살리기 | 박태준 | 최유나 | 3 · 4 · 5 | 카드 2 · 타이밍 3 · 커피 6 |
| 경영-휴먼라이프학부 | 지각한 OT에서 시작해, 정문 앞 40년 된 "행운문구" 컨설팅 | 한석진 | 윤소희 | 1 · 3 · 6 | 커피 2 · 카드 3 · 타이밍 5 |
| 예술-건강학부 | 새벽 운동장 스트레칭, 발목 부상, 객석과 함께 추는 의자 안무 | 서진호 | 강하늘 | 2 · 4 · 5 | 타이밍 1 · 카드 3 · 커피 5 |

### 새 학부 추가하기

AI로 만들 때는 [`STORY_GUIDE.md`](STORY_GUIDE.md)를 통째로 붙여 넣고 "○○대학 ○○학부 스토리를 만들어 줘"라고 하면 됩니다. 직접 넣는 순서는 아래와 같습니다.

1. 대학 폴더(`Assets/Scripts/Stories/Engineering` 등)에 `○○Story.cs` 파일 하나를 만듭니다. `SmartSystemsStory.cs`를 복사해 이름과 내용을 바꾸는 게 가장 빠릅니다. 새 대학이면 폴더도 새로 만듭니다.
2. `College`를 `Stories.Colleges`에 있는 이름(예: `"자연과학대학"`)으로 적습니다. 새 대학 이름이 필요하면 `Stories.Colleges`에 추가하세요(탭은 다섯 개까지 무난합니다).
3. `Story.cs`의 `Stories.All` **맨 끝에** 새 학부를 추가합니다. 순서 번호가 저장 슬롯과 엔딩 도감에 쓰이므로 중간에 넣거나 순서를 바꾸면 안 됩니다.
4. 지켜야 할 틀: 챕터 6개 × 선택 자리 2개 = 12개 중 선택지 6 · 문제 3 · 미니게임 3(카드 · 타이밍 · 커피 하나씩), 엔딩 8개. 순서와 위치는 자유입니다. 한 대학에 학부는 다섯 개까지 타이틀 화면에 들어갑니다.

## 조작

| 동작 | 방법 |
|---|---|
| 대사 넘기기 / 한 번에 표시 | 대화창 클릭, `Space`, `Enter` |
| 선택지 고르기 | 클릭 또는 숫자 키 `1` `2` `3` |
| 한 줄 뒤로 | 대화창 위 "이전" (이미 고른 선택은 되돌리지 않음) |
| 지난 대사 보기 | 대화창 위 "기록" 또는 마우스 휠을 위로 |
| 읽은 대사 건너뛰기 | 대화창 위 "스킵" 켜기, 또는 `Ctrl` 누르고 있기 |
| 설정 열기 / 닫기 | 오른쪽 위 ⚙ 또는 `Esc` |
| 저장 · 불러오기 | 오른쪽 위 📁 |
| 자동 진행 켜기 / 끄기 | 오른쪽 위 ▶ |

## 주요 기능

- **저장 슬롯 5개**: 게임 중 언제든 저장하고, 타이틀의 "이어하기"로 불러옵니다. 이미 저장된 슬롯을 덮어쓰려면 한 번 더 눌러야 합니다.
- **엔딩 도감**: 학부 → 교수님별로 본 엔딩을 모아 봅니다. 아직 못 본 엔딩은 모두 "???"로 가려집니다.
- **대사 기록**: 이번 플레이에서 지나간 대사를 스크롤해서 다시 봅니다.
- **스킵**: 이전 회차까지 포함해 한 번 읽은 대사만 빠르게 넘기고, 처음 보는 대사나 선택지에서 멈춥니다.
- **미니게임 연습**: 타이틀에서 학부별 세 미니게임을 따로 해 볼 수 있습니다. 결과는 호감도에 반영되지 않습니다. 미니게임 중 설정 창을 열면 미니게임 시간도 멈춥니다.
- **설정**: 글자 속도(미리보기 포함), 자동 진행과 속도, 배경음·효과음 볼륨, 화면 효과 켜기/끄기, 창 모드/전체 화면, 타이틀로 돌아가기.
- **연출**: 교수님 그림의 호흡·등장·반응(폴짝 / 흔들림), 선택 직후 표정 변화, 하트·별 파티클, 천천히 움직이는 배경, 챕터 제목 띠. 설정의 "화면 효과"로 끌 수 있습니다.
- **효과음**: 다음 · 이전 · 선택 · 창 열기/닫기 · 토글 · 마우스 올림 · 저장 · 불러오기 · 호감도 상승/하락 · 엔딩 해금 · 챕터 시작이 각각 다른 소리입니다. `Assets/Resources/Audio/Ui/`의 같은 이름 파일을 바꾸면 소리가 바뀝니다.

설정 · 저장 · 도감 · 읽은 대사 기록은 `PlayerPrefs`(`AION.*` 키)에 저장됩니다.
