# AI-ON · 두근두근 캠퍼스

대학교 첫 학기를 배경으로 한 **연애 시뮬레이션 비주얼 노벨**입니다. 열여섯 학과 중 하나의 신입생이 되어 교수님 두 분 중 한 명을 골라, 입학 OT부터 팀 프로젝트 마무리까지 6개 챕터를 함께합니다.

- 엔진: **Unity 6000.3.23f1** (다른 버전으로 열면 프로젝트가 업그레이드되니 꼭 같은 버전을 쓰세요)
- 화면: IMGUI로 직접 그리는 1280×900 고정 캔버스. 창 비율이 달라도 여백(레터박스)으로 맞춥니다.
- 씬: `Assets/Scenes/Main.unity` 하나

## 실행 방법

1. Unity Hub에서 이 폴더를 **6000.3.23f1**로 엽니다.
2. `Assets/Scenes/Main.unity`를 열고 ▶ Play.
3. 빌드: File → Build Profiles에서 `Main` 씬 하나만 넣으면 됩니다.

## 게임 흐름

- **인트로** → **타이틀**(학과 선택 · 이어하기 · 미니게임 연습 · 엔딩 도감 · 설정) → **경험 선택**(컴퓨터공학·물리학은 전공자 / 비전공자, 다른 학과는 경험자 / 입문자) → **교수님 선택** → 챕터 1~6 → **엔딩**
- 챕터마다 선택 자리가 2개씩, 모두 12개입니다. 학과마다 순서와 위치는 다르지만 구성은 같습니다.
  - 일반 선택지 6개: 교수님 성격에 따라 호감도가 오르거나 내립니다.
  - 문제 3개: 경험자는 답을 **직접 입력**하고, 입문자는 쉬운 **객관식**을 풉니다. 정답이면 호감도 +2, 오답이어도 감점은 없습니다.
  - 미니게임 3개: 성적에 따라 호감도 +0~2.
- 엔딩은 학과의 교수님마다 8개입니다. 호감도와 플레이 성향(질문 · 협업 · 관심 · 혼자 해결)에 따라 정해집니다.

### 새 학과 추가하기

AI로 만들 때는 [`STORY_GUIDE.md`](STORY_GUIDE.md)를 통째로 붙여 넣고 "○○학부 ○○학과 스토리를 만들어 줘"라고 하면 됩니다. 직접 넣는 순서는 아래와 같습니다.

1. 학부 폴더(`Assets/Scripts/Stories/Engineering` 등)에 `○○Story.cs` 파일 하나를 만듭니다. `SmartSystemsStory.cs`를 복사해 이름과 내용을 바꾸는 게 가장 빠릅니다. 새 학부이면 폴더도 새로 만듭니다.
2. `College`를 `Stories.Colleges`에 있는 이름(예: `"자연과학부"`)으로 적습니다. 새 학부 이름이 필요하면 `Stories.Colleges`에 추가하세요(탭은 다섯 개까지 무난합니다).
3. `Story.cs`의 `Stories.All` **맨 끝에** 새 학과를 추가합니다. 순서 번호가 저장 슬롯과 엔딩 도감에 쓰이므로 중간에 넣거나 순서를 바꾸면 안 됩니다.
4. 지켜야 할 틀: 챕터 6개 × 선택 자리 2개 = 12개 중 선택지 6 · 문제 3 · 미니게임 3(종류는 `MiniGameKind` 19종 중 자유, 겹치지 않게), 엔딩 8개. 순서와 위치는 자유입니다. 한 학부에 학과는 다섯 개까지 타이틀 화면에 들어갑니다.

## 주요 기능

- **저장 슬롯 5개**: 게임 중 언제든 저장하고, 타이틀의 "이어하기"로 불러옵니다. 이미 저장된 슬롯을 덮어쓰려면 한 번 더 눌러야 합니다.
- **엔딩 도감**: 학과 → 교수님별로 본 엔딩을 모아 봅니다. 아직 못 본 엔딩은 모두 "???"로 가려집니다.
- **대사 기록**: 이번 플레이에서 지나간 대사를 스크롤해서 다시 봅니다.
- **스킵**: 이전 회차까지 포함해 한 번 읽은 대사만 빠르게 넘기고, 처음 보는 대사나 선택지에서 멈춥니다.
- **미니게임 연습**: 타이틀에서 학과별 미니게임 세 개를 따로 해 볼 수 있습니다. 결과는 호감도에 반영되지 않습니다. 미니게임 중 설정 창을 열면 미니게임 시간도 멈춥니다.
- **설정**: 글자 속도(미리보기 포함), 자동 진행과 속도, 배경음·효과음 볼륨, 화면 효과 켜기/끄기, 창 모드/전체 화면, 타이틀로 돌아가기.
- **연출**: 교수님 그림의 호흡·등장·반응(폴짝 / 흔들림), 선택 직후 표정 변화, 하트·별 파티클, 천천히 움직이는 배경, 챕터 제목 띠. 설정의 "화면 효과"로 끌 수 있습니다.
- **효과음**: 다음 · 이전 · 선택 · 창 열기/닫기 · 토글 · 마우스 올림 · 저장 · 불러오기 · 호감도 상승/하락 · 엔딩 해금 · 챕터 시작이 각각 다른 소리입니다. `Assets/Resources/Audio/Ui/`의 같은 이름 파일을 바꾸면 소리가 바뀝니다.

설정 · 저장 · 도감 · 읽은 대사 기록은 `PlayerPrefs`(`AION.*` 키)에 저장됩니다.
